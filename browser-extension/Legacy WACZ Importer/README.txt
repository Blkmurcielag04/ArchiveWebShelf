ARCHIVEWEBSHELF LEGACY WACZ IMPORTER

This is the preserved import-only extension. It can add a WACZ file that another program already created.

To load it in Chrome or Brave:
1. Start Archive Shelf and keep its server window open.
2. Open chrome://extensions or brave://extensions.
3. Turn on Developer mode and choose Load unpacked.
4. Select this Legacy WACZ Importer folder.

The recommended Archive Shelf Recorder extension also imports existing WACZ files and can record new pages. The legacy option remains here if you prefer the old, import-only popup.
