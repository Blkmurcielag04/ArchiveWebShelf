# Version history

## 1.0.0 - 2026-10-22

First public release of Archive Shelf.

- Organize local web archives into folders.
- Record pages with the included browser extension and save WACZ files to the Shelf.
- Import existing WACZ files through the extension or organizer.
- Check whether the current page is already listed in saved WACZ archives.
- Browse archives using the bundled ReplayWeb.page reader.
- Manage saved captures within an archive using **Manage saved pages**.
- Start the local server using the Windows launcher.
- Read the included setup, Python path, and connection guides.

### Known limitations

Back navigation needs further investigation. Interactive content must be
loaded through browsing, scrolling, or clicking while recording.
See [BUGS.txt](BUGS.txt) for details and workarounds.

The Archive Shelf release and ready-to-load extension are version **1.0.0**.
The readable recorder source is based on upstream ArchiveWeb.page **0.17.5**.
